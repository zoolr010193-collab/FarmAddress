🔐 MANUAL HTTPS SETUP (FOR YOUR OWN SERVER)
════════════════════════════════════════════════════════════════════════════

If hosting on your own server:

STEP 1: GET SSL CERTIFICATE (Let's Encrypt - FREE)
────────────────────────────────────────────────────

Option A: Using Certbot (Recommended)

1. Install Certbot
   # Ubuntu/Debian
   sudo apt-get install certbot python3-certbot-nginx
   
   # macOS
   brew install certbot

2. Get certificate
   sudo certbot certonly --standalone -d yourdomain.com
   
   Follow prompts:
   - Enter email
   - Agree to terms
   - Provide domain name

3. Verify success
   Certificate saved in: /etc/letsencrypt/live/yourdomain.com/

4. Configure renewal
   sudo certbot renew --dry-run
   Automatically renews before expiration

5. Use certificate in your web server
   Point web server to:
   - /etc/letsencrypt/live/yourdomain.com/fullchain.pem
   - /etc/letsencrypt/live/yourdomain.com/privkey.pem


Option B: Using cPanel/WHM

1. Access WHM
   WHM → AutoSSL
   Select "Let's Encrypt"
   Auto-install HTTPS

2. Enable Auto Renewal
   Set to automatic
   Verifies domain

3. Done!
   Your domain now has HTTPS


STEP 2: CONFIGURE WEB SERVER
────────────────────────────────────────────────────────────────

APACHE (httpd.conf or .htaccess)
─────────────────────────────────
# Redirect HTTP to HTTPS
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteCond %{HTTPS} off
  RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</IfModule>

# Enable HTTPS
<VirtualHost *:443>
  ServerName yourdomain.com
  SSLEngine on
  SSLCertificateFile /path/to/certificate.pem
  SSLCertificateKeyFile /path/to/private.key
  DocumentRoot /path/to/farmaddress
</VirtualHost>


NGINX (nginx.conf)
──────────────────
# Redirect HTTP to HTTPS
server {
  listen 80;
  server_name yourdomain.com;
  return 301 https://$server_name$request_uri;
}

# HTTPS configuration
server {
  listen 443 ssl;
  server_name yourdomain.com;
  
  ssl_certificate /path/to/certificate.pem;
  ssl_certificate_key /path/to/private.key;
  
  location / {
    root /path/to/farmaddress;
    try_files $uri $uri/ /index.html;
  }
}


STEP 3: PREPARE YOUR APP
────────────────────────────────────────────────────────────────

1. Update manifest.json URLs
   Replace placeholders with your domain:
   
   "start_url": "https://yourdomain.com/index.html"
   "icons": [
     {
       "src": "https://yourdomain.com/images/icon-192x192.png",
       ...
     }
   ]

2. Update pwabuilder.json
   "url": "https://yourdomain.com"
   "launchUrl": "https://yourdomain.com"

3. Upload icon images
   Create high-quality PNG icons:
   - 192x192 pixels (general)
   - 512x512 pixels (general)
   - 192x192 maskable
   - 512x512 maskable
   Upload to: /images/ folder

4. Test on HTTPS
   Visit: https://yourdomain.com
   Verify everything loads
   Check browser console for errors


STEP 4: VERIFY HTTPS WORKS
────────────────────────────────────────────────────────────────

1. Test SSL Certificate
   https://www.ssllabs.com/ssltest/
   Enter your domain
   Should show A or A+

2. Test PWA
   Open app in HTTPS URL
   DevTools → Application
   Check Service Worker
   Should see "activated and running"

3. Test Offline
   Check offline in DevTools
   Page should still load
   All assets should cache

4. Test Installation
   Should see install prompt
   Installation should work
   App should install successfully
