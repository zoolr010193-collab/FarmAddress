📋 CACHING STRATEGY
════════════════════════════════════════════════════════════════════════════

HTML PAGES:
├── Strategy: Network First
├── Tries: Network first, fallback to cache
├── Updates: Immediately when online
└── Offline: Serves cached version

STYLES & SCRIPTS:
├── Strategy: Cache First
├── Tries: Cache first, network fallback
├── Updates: On next visit
└── Performance: Fastest loading

IMAGES:
├── Strategy: Cache First
├── Tries: Cache first, network fallback
├── Updates: Lazy cached
└── Offline: Placeholder if missing

DATA/API:
├── Strategy: Network First
├── Tries: Network first, cache fallback
├── Updates: Always fresh when online
└── Offline: Cached data available
