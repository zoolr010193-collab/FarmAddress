🛠️ FOR DEVELOPERS
==================

Adding translations to a page:

1. Add i18n.js to HTML:
   <script src="i18n.js"></script>

2. Use data-i18n on elements:
   <h1 data-i18n="hero.title">Default text</h1>

3. For inputs/placeholders:
   <input data-i18n-placeholder="common.search">

4. In JavaScript:
   const text = t('nav.farms');
   const text2 = i18n.t('nav.products');

🎨 CUSTOMIZATION
=================

Change default language:
Edit i18n.js line:
this.currentLanguage = localStorage.getItem('farmAddress_language') || 'ar';
↓
Change 'ar' to 'en' for English default


Change toggle button text/icon:
Edit index.html (and other pages):
<span class="language-toggle-icon">🌐</span>
Change emoji or add text


Adjust styling:
Edit i18n.css for RTL/LTR specific styles


❓ TROUBLESHOOTING
===================

Q: Language not changing?
A: Ensure i18n.js loads before other scripts
   Check browser console for errors

Q: Text not translating?
A: Check if element has data-i18n attribute
   Verify key exists in i18n.js

Q: Direction not switching?
A: Clear browser cache
   Check HTML dir attribute in inspector
   Verify i18n.css is loaded

Q: Preference not saving?
A: Check localStorage enabled
   Try incognito/private mode
