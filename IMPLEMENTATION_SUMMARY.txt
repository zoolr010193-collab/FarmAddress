🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════

FOR END USERS:
1. Visit: http://localhost:8000
2. Click the 🌐 button in the navigation
3. Watch the page transform instantly
4. Your language preference is saved automatically

FOR DEVELOPERS:

Adding text to translate:

In HTML:
<button data-i18n="cart.checkout">Default Text</button>
<input data-i18n-placeholder="common.search">

In JavaScript:
const label = t('nav.cart');
const text = i18n.t('hero.title');

Adding new translations:

1. Edit i18n.js
2. Find the translations object
3. Add to BOTH ar and en sections:

ar: {
    "your.key": "النص بالعربية",
}

en: {
    "your.key": "English text",
}
