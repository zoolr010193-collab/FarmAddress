FARMADDRESS - LANGUAGE SYSTEM GUIDE
====================================

✅ LANGUAGE SUPPORT ADDED
========================
The app now supports:
- Arabic (العربية) - Default, RTL
- English - LTR

🎯 HOW TO USE TRANSLATIONS
==========================

IN HTML FILES:
--------------
Use data-i18n attribute for text content:

<button data-i18n="nav.cart">السلة</button>

For input placeholders:

<input type="text" data-i18n-placeholder="common.search">

For title tag:

<title data-i18n-title="page.title">...</title>


IN JAVASCRIPT FILES:
--------------------
Use the t() function or i18n.t():

const cartLabel = t('nav.cart');
const welcome = i18n.t('farmer.welcome');


🔄 HOW LANGUAGE TOGGLE WORKS
=============================
1. User clicks the 🌐 Language button in the header
2. Language switches from Arabic to English or vice versa
3. localStorage saves the preference (farmAddress_language)
4. Page automatically updates all translated text
5. HTML dir attribute changes (rtl ↔ ltr)


📝 ADDING NEW TRANSLATIONS
==========================

1. Open i18n.js
2. Find the translations object
3. Add your new key-value pair to BOTH ar and en:

ar: {
    "your.new.key": "النص بالعربية",
    ...
}

en: {
    "your.new.key": "English Text",
    ...
}

4. Use in HTML:
   <element data-i18n="your.new.key">Default Text</element>

5. Use in JavaScript:
   t('your.new.key')


🎨 CSS & DIRECTION (RTL/LTR)
=============================
The system automatically:
- Sets html[lang] attribute
- Sets html[dir] attribute (rtl for Arabic, ltr for English)
- Applies CSS fixes in i18n.css for proper alignment

To target specific languages in CSS:

[dir="rtl"] .my-element { /* Arabic specific */ }
[dir="ltr"] .my-element { /* English specific */ }
[data-lang="ar"] .my-element { /* Arabic */ }
[data-lang="en"] .my-element { /* English */ }


📱 MOBILE SUPPORT
=================
The language toggle button is responsive and appears in:
- Desktop: In the navigation bar
- Mobile: Part of the nav-actions area

Adjust positioning in i18n.css media queries if needed.

❓ TROUBLESHOOTING
===================

Issue: Translations not updating
- Check if i18n.js is loaded before other scripts
- Verify data-i18n attribute keys exist in i18n.js
- Open browser console for error messages

Issue: Text direction not changing
- Clear browser cache
- Check HTML dir attribute in Inspector
- Ensure i18n.css is loaded

Issue: Missing translation
- Check translations object in i18n.js
- Key might be misspelled
- Add missing translation key to both ar and en
