🚀 HOW TO RUN
═════════════════════════════════════════════════════════════════════════

1. Start the local server:
   cd /Users/user/FarmAddress
   python3 -m http.server 8000

2. Open in browser:
   http://localhost:8000

3. Try the language feature:
   Click the 🌐 button in the navigation

4. Test farmer panel:
   Go to Farmer Panel → Login
   Demo credentials: admin / farm123
